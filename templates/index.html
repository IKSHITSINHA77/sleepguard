About SleepGuard

A student machine-learning project exploring classification of sleep-disorder patterns using sleep and lifestyle attributes.

Machine-learning models

  • Support Vector Machine (SVM)
  • K-Nearest Neighbours (KNN)
  • Decision Tree
  • Random Forest
  • Artificial Neural Network (MLP)
  • Soft-voting ensemble

Evaluation approach

The training pipeline compares models using repeated stratified cross-validation, selects a model using macro F1, and evaluates the selected model on a separate hold-out test split.

Important limitation: SleepGuard is not a medical device. Predictions can be incorrect and must not be used to diagnose, treat or make medical decisions. Synthetic data is for software testing only and must not be presented as real-world model evidence.
